# Numerical Solvers & Calculation Scripts

## Overview
Analytical scripts written in Python and MATLAB to calculate gear geometry, kinematics, bending stress limits, and drivetrain efficiency matrices.

## Code Modules
* `gear_kinematics.py`: Calculates gear ratios, pitch circle diameters, and linear tooth velocities.
* `Lewis_bending_stress.py`: Evaluates tooth bending stress using the Lewis and AGMA stress equations for both spur and helical profiles.
* `mesh_efficiency.m`: MATLAB solver for computing dynamic gear meshing power losses and thermal efficiency.

## Dependencies
* Python 3.x (`numpy`, `matplotlib`, `scipy`)
* MATLAB / GNU Octave
