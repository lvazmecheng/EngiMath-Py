# 3D CAD Models

## Overview
This folder contains the complete 3D assembly models for both the Spur and Helical Planetary Gearbox configurations.

## Contents
* `spur-gearbox.step`: Standard STEP file for the complete spur planetary gear assembly.
* `helical-gearbox.step`: Standard STEP file for the complete helical planetary gear assembly.
* `glTF or GLB`: Web-optimized 3D model file formatted for real-time browser rendering on GitHub Pages.

## Software & Parameters
* **Primary CAD Environment:** SOLIDWORKS Design Student
