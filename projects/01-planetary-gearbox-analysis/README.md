# Project 01: Planetary Gearbox Comparative Analysis (Spur vs. Helical)

## Overview
This project presents a design and performance comparison between spur and helical planetary gear assemblies operating under identical torque and speed conditions.

## Project Directory Structure
* [`cad/`](./cad/): 3D geometry files in standard STEP format alongside lightweight models for web rendering.
* [`drawings/`](./drawings/): 2D manufacturing drawings with geometric dimensioning and tolerancing (GD&T) plus external SOLIDWORKS cloud source links.
* [`fea-cfd/`](./fea-cfd/): Finite Element Analysis (FEA) stress/deformation plots and Computational Fluid Dynamics (CFD) gear splash lubrication maps.
* [`scripts/`](./scripts/): Python scripts for kinematic calculations and numerical models
