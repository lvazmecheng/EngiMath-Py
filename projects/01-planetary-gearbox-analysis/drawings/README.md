# 2D Engineering Drawings & Cloud Assemblies

## Overview
Contains fully dimensioned, GD&T-compliant 2D production drawings detailing manufacturing tolerances, fit limits, and Bill of Materials (BOM) callouts.

## Contents
* `spur-assembly.pdf`: Vector PDF drawing for the spur planetary arrangement (orthographic views, section cuts, BOM).
* `helical-assembly.pdf`: Vector PDF drawing for the helical planetary arrangement (orthographic views, section cuts, BOM).
* `solidworks-links.md`: External cloud links (e.g., GrabCAD / 3DEXPERIENCE) to inspect interactive native `.SLDPRT` and `.SLDASM` files.
